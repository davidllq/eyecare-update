# 护眼闹钟 - EyeCare Alarm

一款帮助用户保护视力健康的工具类应用，提供智能计时、定时提醒、个性定制、数据统计等功能，帮助用户养成良好的用眼习惯。

> ⚠️ **当前为测试版本**：本应用正在进行APP备案审核，正式版即将上线各大应用市场。当前版本仅供测试使用，请勿用于商业用途。

## ✨ 功能特性

### 🕐 智能计时
- 自定义护眼间隔时间（1-60分钟可选）
- 支持多种提醒方式（声音、震动、悬浮窗）
- 智能识别屏幕状态，自动暂停/恢复计时

### 🔔 定时提醒
- 到时间自动弹出提醒悬浮窗
- 支持"稍后提醒"功能（5/10/15分钟）
- 提醒时可选择"已休息"完成当前周期

### ⚙️ 个性定制
- 自定义提醒铃声
- 自定义提醒文案
- 深色/浅色主题切换
- 悬浮窗样式自定义

### 📊 数据统计
- 每日护眼时长统计
- 每周/每月趋势图表
- 用眼习惯分析
- 成就系统激励

### 🛡️ 后台保活
- 前台服务保活机制
- 支持自启动管理引导
- 电池优化白名单引导
- 多种厂商机型适配

## 📱 系统要求

- **操作系统**：Android 7.0 (API 24) 及以上
- **存储空间**：至少 50MB 可用空间
- **权限要求**：
  - 悬浮窗权限（用于提醒显示）
  - 前台服务权限（用于后台保活）
  - 震动权限（用于震动提醒）
  - 通知权限（用于通知提醒）
